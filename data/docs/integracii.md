# Интеграции

## Доступные интеграции
Продукт интегрируется с 1С (выгрузка товаров и остатков), Kaspi.kz (приём заказов),
Instagram/WhatsApp для приёма сообщений в единую панель, а также предоставляет
открытый REST API и вебхуки для собственных интеграций.

## Настройка вебхуков
В разделе "Настройки → API" можно создать вебхук на события: новая продажа, новый
возврат, изменение остатков. Вебхук отправляет POST-запрос с JSON-телом на указанный
URL. При ошибке доставки (код ответа не 2xx) система делает до 5 повторных попыток
с экспоненциальной задержкой.

## Лимиты API
Стандартный тариф — 60 запросов в минуту на аккаунт. Тариф "Бизнес" — 300 запросов
в минуту. При превышении лимита API возвращает код 429 с заголовком Retry-After.
